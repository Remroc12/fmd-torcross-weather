# FMD Torcross Marine Weather

Deploy as Render Web Service, runtime Node, build command `npm install`, start command `npm start`.

Environment variables: `CCO_API_KEY` (your domain-approved key), `CCO_REFERER` (e.g. `https://fmd-torcross-weather.onrender.com/`). CCO keys are domain-bound; the example/development key published in their docs is NOT approved for your Render domain. Request your own domain-authorised key from CCO.

This app is not a certified navigational/operational decision tool. Proposed anchorage is unverified. Marine chart overlay is OpenSeaMap, not official hydrographic chart.
